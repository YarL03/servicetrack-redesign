# Направления редизайна

Предмет: рабочее место диспетчера, администратора и исполнителя сервисных заявок. Задача — видеть состояние работ и доводить заявку от назначения до принятого результата. Все три варианта содержат одинаковый функциональный охват.

## v1 · Контур
Светлое рабочее пространство с постоянным синим навигационным акцентом. Подходит для длительной работы со списками и сложными формами. Отличительный элемент — вертикальная полоса текущего этапа заявки и связанная с ней история действий.
- Цвета: фон #F4F6FA, поверхность #FFFFFF, текст #17243D, вторичный #627086, акцент #2457D6, тон #EAF0FF.
- Шрифты: заголовки Trebuchet MS / sans-serif, текст Segoe UI / sans-serif, данные Consolas / monospace.
- Компоновка: постоянное меню → широкий список → контекст справа. На телефоне карточки, выдвижное меню и нижняя навигация.

## v2 · Пульт
Горизонтальная навигация и компактные рабочие журналы под тёмной верхней полосой. Предназначен для диспетчерской с большим количеством заявок. Отличительный элемент — связанная полоса состояний работ, которая ведёт от нового обращения к закрытой заявке.
- Цвета: фон #EDF3F2, поверхность #FFFFFF, текст #173C40, вторичный #526F72, акцент #007F75, верхняя полоса #143C40.
- Шрифты: заголовки Arial / sans-serif, текст Segoe UI / sans-serif, данные Courier New / monospace.
- Компоновка: верхнее меню → строка инструментов → плотная рабочая сетка. На узких экранах основная навигация сворачивается в доступное меню.

## v3 · Маршрут
Спокойная светлая фиолетовая оболочка с узкой боковой навигацией и выраженной последовательностью работы. Подходит для исполнителя и руководителя, которым важны контекст и следующий шаг. Отличительный элемент — крупная карточка маршрута заявки с понятными этапами и контекстной колонкой.
- Цвета: фон #F5F3FA, поверхность #FFFFFF, текст #302C4A, вторичный #6F6786, акцент #7352B8, тон #EDE6FA.
- Шрифты: заголовки Verdana / sans-serif, текст Arial / sans-serif, данные Consolas / monospace.
- Компоновка: компактная навигация → приоритетная область работы + контекст. На телефоне последовательная лента и фиксированное действие формы.

## Проверка направления до реализации
Три концепции отличаются архитектурой навигации, плотностью и расположением контекста, а не только цветами. Исключены декоративные рекламные hero-блоки, вымышленные метрики эффективности и несуществующие операции. Карты и графики используют локальные демонстрационные данные. Редизайн мобильной веб-версии отмечен как предложение: текущая версия предлагает APK.

## Адаптация
| Диапазон | Контрольная ширина | Поведение |
| --- | --- | --- |
| xs: 0–599 | 390; дополнительно 320 | одна колонка, таблицы-карточки, полноэкранные диалоги, нижняя навигация |
| sm: 600–899 | 768 | две колонки там, где хватает места, меню в drawer |
| md: 900–1199 | 1024 | компактная навигация, таблицы, формы в две колонки |
| lg: 1200–1535 | 1440 | полное меню, контекст сбоку, трёхпанельный конструктор |
| xl: ≥1536 | 1920 | ограничение ширины чтения, расширенная сетка дашборда |

Границы проверяются на 599/600, 899/900, 1199/1200, 1535/1536. Размеры — CSS px, адаптация непрерывная.

## Тёмные варианты

Все три направления имеют полноценную тёмную палитру. Компоновка сохраняется, поверхности и семантические состояния адаптированы отдельно; пользовательские медиа не инвертируются. Токены и правила описаны в [DARK-THEMES.md](DARK-THEMES.md).
