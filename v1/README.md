# v1 · Контур

[Открыть макеты](index.html). Светлое рабочее пространство с постоянным боковым меню и контекстной колонкой заявки. Синий акцент связывает выбранный раздел, текущий этап и основное действие. Формы и таблицы рассчитаны на длительную ежедневную работу.

Все 142 экрана доступны в селекторе нижней панели и в [общем каталоге](../index.html?variant=v1). Адаптация: 600 / 900 / 1200 / 1536 px; минимально проверяемая ширина 320 px. PNG в `previews/` показывают дашборд, список заявок, рабочую форму и конструктор на пяти размерах.

Макеты используют общие файлы из `../shared`; для передачи сохраняйте всю папку `redesign`.

## Цветовые темы

[Светлая](index.html?theme=light) · [Тёмная](index.html?theme=dark). Переключатель солнце/луна находится в верхней панели; выбор сохраняется, поля и диалоги остаются на месте. Тёмные PNG: `previews/dark/`.
