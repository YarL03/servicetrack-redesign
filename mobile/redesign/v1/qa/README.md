# Проверка макетов

Дата: 19.11.2026. Браузер: локальный headless Chromium. [Машиночитаемый отчёт](report.json), [галерея PNG](../previews/index.html).

Проверено 24 экрана на ширинах 320 / 360 / 390 / 430 px: 96 основных комбинаций и 4 дополнительных для режима «По улице» — всего 100, без горизонтального переполнения страницы и содержимого. Отдельно сохранены desktop-каталог, сравнение навигации и обзор уведомлений, девять тёмных экранов и форма при высоте 600 px.

82 сценарные проверки. Исходные 33: поиск по улице/абоненту/внешнему номеру, пустой результат, сочетание фильтра и запроса, статусы, форма с фото, восстановление черновика после reload, проверка фактических данных, online/offline-завершение, блокировка ожидающей формы, перенос в историю, обязательное фото недопуска, текст и вложения чата, изоляция файлов по заявкам, реальный локальный файл и его предпросмотр/удаление, очередь сообщения без сети, запрет ложного успеха retry без связи, Browser Back, клавиатурный фокус и Escape в диалоге, возврат к позиции формы после чата, ошибка сообщения и повтор, доступность основной кнопки при коротком viewport.

JavaScript-ошибок в проверенных сценариях не зафиксировано. PNG просмотрены визуально: сравнение навигации, очередь, форма, проверка результата, чат в светлой и тёмной теме, вложение перед отправкой; обзор уведомлений, лента в обеих темах, событие, настройки, сообщение внутри формы, разрешение, недоступная заявка и профиль Ивана Иванова.

После уточнения имени и уведомлений добавлены 42 проверки в `notifications.cjs`: имя и инициалы, колокольчик и вход из профиля, совместная работа фильтров, автоотметка отдельного события, переход в правильную заявку/сообщение, возврат к подборке, mark-unread, удаление/отмена, bulk-read без побочного прочтения чата, очередь отметок без сети, запрет удаления без сети, недоступная локальная копия, повтор после подключения, отказ в доступе, ошибка отметки и повтор, загрузка/пусто/ошибка обновления, добровольное разрешение и отказ, настройки доставки, проверка тихих часов, приватность предпросмотра, сохранение фокуса/курсора/позиции формы, закрытие баннера без прочтения, возврат из чата, дедупликация события в открытом диалоге и переход из демонстрационного push.

Название — «Сервис Трек», исполнитель — Иван Иванов / ИИ, логотип — исходный assets/logo.png мобильного проекта. SHA-256 копии совпадает с оригиналом. В галерее 60 PNG. На 320 px поля тихих часов расположены вертикально: это исправляет обнаруженное переполнение.

Добавлены 7 проверок адресной группировки: отдельные дома по умолчанию, объединение разных домов одной улицы с сохранением точного адреса, переход к нужной заявке, возврат к раскрытым группам и прежней прокрутке, обратное разделение без потери заявок, сохранение выбора после reload и обновление групп после изменения активных заявок. PNG обоих режимов просмотрены; «По улице» также сохранён в тёмной теме.

Запуск из корня мобильного проекта:

```bash
node tasks/redesign/v1/qa/browser.cjs
```

`REDESIGN_BROWSER` задаёт путь к Chromium. Скрипт использует Chrome DevTools Protocol через pipe, сохраняет PNG и `report.json`. В среде с ограничением системных вызовов браузера потребуется разрешённый запуск вне sandbox. Сеть не используется. Аргумент `--comparison-only` обновляет только PNG сравнения навигации, сохраняя последний полный отчёт.

Ограничения: это проверка HTML-прототипа. Нативные permission-dialogs, камера, запись аудио, реальная загрузка на сервер, VoiceOver/TalkBack, системная клавиатура Android/iOS и производительность на устройстве не тестировались. Визуальные состояния синхронизации не заменяют тесты существующего offline-движка приложения.
