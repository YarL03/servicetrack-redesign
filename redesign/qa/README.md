# Проверка «Контура»

Из корня проекта выполните обе команды. Они открывают локальные HTML в Chromium, проверяют экраны и записывают PNG в `v1/previews` и `previews`.

```bash
node tasks/redesign/qa/browser-check.cjs --full --theme=light --screenshots
node tasks/redesign/qa/browser-check.cjs --full --theme=dark --screenshots
```

Путь к другому установленному Chromium можно передать через `REDESIGN_BROWSER=/path/to/chrome`. Для короткой проверки уберите `--full`. Параметр `--screenshots` управляет записью снимков.

## Покрытие

- Все 142 экрана открываются на ширинах 320, 390, 599, 600, 768, 899, 900, 1024, 1199, 1200, 1440, 1535, 1536 и 1920 px. Для каждого экрана проверяются отрисованный ID, заголовок, хлебные крошки, цели переходов, границы полей и горизонтальное переполнение.
- Диалоги открываются поверх страницы на 320 и 1440 px. Проверяются фокус, закрытие, обязательные поля, доступ к навигации, этапы конструктора и контекст заявки.
- В строках с подписанными полями сравниваются вертикальные центры соседних элементов управления. В сводном отчёте дополнительно проверяются перенос подписи на две строки и нажатие «Сформировать». Превью отчёта сохраняется на ширине 1440 px.
- В конструкторе проверяется перенос мышью и касанием за ручки, в том числе между колонками на планшете и в промежуток между группами. Проверяются отмена через Escape, стрелки с клавиатуры и сохранение выбранной группы с её значением после перестановки.
- На обзоре проверяются мобильные фильтры, выбранный период при изменении ширины и таблица значений графика.
- В каталоге проверяются поиск, выбор экрана и ширины, мобильный список, ссылка на открытый экран, синхронизация темы в обе стороны и сохранение черновика внутри фрейма.
- Для тёмной темы скрипт дополнительно проверяет цвета поверхностей и текста полей.

Подробные результаты находятся в [светлом отчёте](v1-browser-report.json) и [тёмном отчёте](v1-dark-browser-report.json). Файлы отчётов предыдущих прогонов сохраняют историю проверок. Массовый обход использует `RD.render(id)`, переходы по ссылкам и возврат браузером проверяются отдельными сценариями.
