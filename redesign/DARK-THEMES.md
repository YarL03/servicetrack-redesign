# Тёмные темы

Тёмная тема сохраняет компоновку и характер «Контура». Цвета интерфейса меняются через `html[data-theme="dark"]`; экран и введённые значения остаются на месте.

| Токен | v1 · Контур |
| --- | --- |
| Основной фон | `#101722` |
| Поверхность панели | `#192435` |
| Вторичная поверхность | `#202E42` |
| Основной текст | `#E8EEF8` |
| Вторичный текст | `#A8B8CE` |
| Граница | `#33435B` |
| Акцент | `#8BB0FF` |
| Акцентная поверхность | `#243B60` |

На ярких основных кнопках используется тёмный текст для читаемого контраста. Состояния «Информация», «Успех», «Предупреждение» и «Ошибка» сохраняют общие значения и текстовые подписи. Таблицы, конструктор, загрузка файлов, уведомления, тарифы, карточки заявок и диалоги получают тёмные поверхности и нативную схему `color-scheme: dark`.

У схемы карты меняются цвета поверхности, дорог, подписей и маркеров; иллюстрация прибора и пользовательские медиа не инвертируются. Диаграммы используют синий акцент и отдельную вторичную серию. При печати остаётся светлая палитра документа.

Реализация палитр: [shared/dark.css](shared/dark.css). Она подключается после общих стилей компонентов. Семантические цвета «Контура» дополняет [v1/theme.css](v1/theme.css).
