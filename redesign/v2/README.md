## Переписка

Откройте «Чаты» в навигации или вкладку «Чат» в карточке заявки. На широком экране список и переписка расположены рядом. На телефоне ссылка «Все чаты» возвращает из диалога к списку.

В списке работают поиск по адресу, номеру, виду работ и исполнителю, фильтры «Активные», «Непрочитанные», «Архив» и четыре группировки мобильной v2. Счётчик в навигации показывает количество непрочитанных сообщений, во вкладке списка — количество непрочитанных диалогов. Открытие диалога помечает сообщения этой заявки как прочитанные.

Напишите ответ или приложите файлы скрепкой. При переходе между заявками текст и файлы остаются в своём черновике. Enter отправляет сообщение, Shift+Enter добавляет новую строку. Нажмите имя вложения для просмотра или скачивания. Если в сообщении несколько вложений, между ними можно переходить прямо в просмотрщике. [Чат № 10428](index.html#chat-10428) · [Снимок на компьютере](previews/chat-1440-light.png) · [Снимок на телефоне](previews/chat-390-dark.png).

## Распределение файлов по полям

Нажмите заголовок «Нераспределённые файлы», чтобы свернуть или развернуть список. Счётчик виден в обоих состояниях. Выбор сохраняется при переходах между вложениями и формой этой заявки до перезагрузки макета. [Свёрнутый раздел](previews/files-collapsed-1440-light.png).

1. Откройте «Нераспределённые файлы» в заявке № 10428. Алексей Морозов отправил фото пломбы, видео проверки, подписанный акт и запись звука. Все четыре файла доступны также в исходных сообщениях. [Вложения заявки](index.html#request-files).
2. У фотографии нажмите «Прикрепить к полю». Выберите «Фото установленного прибора» или смешанное поле «Дополнительные материалы» и подтвердите выбор. Файл исчезнет из очереди, а у вложения в переписке появится название поля. [Выбор поля](previews/assignment-1440-light.png).
3. Откройте рабочую форму. Прикреплённые файлы видны у своих полей. В режиме редактирования можно начать и с поля. Кнопка «Из нераспределённых» покажет совместимые файлы этой заявки. Для смешанного поля учитывается лимит в пять файлов. [Рабочая форма](index.html#request-object-edit) · [Результат в поле формы](previews/form-390-light.png).
4. Нажмите название выбранного поля у вложения, чтобы открыть это место в форме, перенести файл в другое поле или вернуть в нераспределённые. Отмена сохраняет прежнее назначение.

[Заявка № 10426](index.html#request-10426) показывает отдельную очередь с актом другого исполнителя. [Заявка № 10425](index.html#chat-10425) показывает переписку с вложением при отсутствии файловых полей. Файлы, отправленные диспетчером, доступны в чате. Очередь распределения содержит только материалы исполнителя.

## Просмотр и проверка

Макет работает с диска. Для переноса сохраните папку `redesign` целиком. V2 использует общие экраны и оформление «Контура» из соседних папок `shared` и `v1`. Адреса, статусы и исполнители соответствуют веб-реестру v1. Переписка и распределение файлов работают локально в открытой странице. Перезагрузка возвращает демонстрационные данные. Выбранная тема и группировка запоминаются в браузере.

Проверку в Chromium можно повторить из корня репозитория. Параметр `--screenshots` обновляет PNG в `previews`. Путь к другому Chromium задаётся переменной `REDESIGN_BROWSER`.

```bash
node tasks/redesign/v2/qa/check.cjs --screenshots
```
