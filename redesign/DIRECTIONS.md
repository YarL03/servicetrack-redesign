# Дизайн «Контура»

Предмет: рабочее место диспетчера, администратора и исполнителя сервисных заявок. Задача — видеть состояние работ и доводить заявку от назначения до принятого результата.

## v1 · Контур
Светлое рабочее пространство с постоянным синим навигационным акцентом. Подходит для длительной работы со списками и сложными формами. Отличительный элемент — вертикальная полоса текущего этапа заявки и связанная с ней история действий.
- Цвета: фон #F3F5F9, поверхность #FFFFFF, текст #1C2B43, вторичный #596980, акцент #2858D6, тон #EBF1FF. Граница панелей #DCE3ED; граница редактируемых полей #8998AE.
- Шрифты: заголовки Segoe UI Variable / Segoe UI / system-ui, основной текст Segoe UI / system-ui; идентификаторы в данных ui-monospace / Consolas, табличные цифры. Размер заголовка 30 px, основного текста 14 px, таблиц 13 px; подписи и статусы 11–12 px.
- Компоновка: постоянное сгруппированное меню → единая панель инструментов и списка → контекст справа. Вертикальные этапы и смена статуса открывают правую колонку общей информации о заявке. До 1200 px контекст раскрывается перед содержимым. На телефоне карточки, выдвижное меню и нижняя навигация.
- Обновление 18.11.2026: более выраженная иерархия заголовков, согласованный размер действий и полей, отдельный сигнал задержки, полноценное управление раскрываемым контекстом с клавиатуры. Подробнее: [v1/README.md](v1/README.md).

## Адаптация
| Диапазон | Контрольная ширина | Поведение |
| --- | --- | --- |
| xs: 0–599 | 390; дополнительно 320 | одна колонка, таблицы-карточки, полноэкранные диалоги, нижняя навигация |
| sm: 600–899 | 768 | две колонки там, где хватает места, меню в drawer |
| md: 900–1199 | 1024 | компактная навигация, таблицы, формы в две колонки |
| lg: 1200–1535 | 1440 | полное меню, контекст сбоку, трёхпанельный конструктор |
| xl: ≥1536 | 1920 | ограничение ширины чтения, расширенная сетка дашборда |

Границы проверяются на 599/600, 899/900, 1199/1200, 1535/1536. Размеры — CSS px, адаптация непрерывная.

## Тёмная тема

Компоновка сохраняется, поверхности и семантические состояния адаптированы отдельно; пользовательские медиа не инвертируются. Токены и правила описаны в [DARK-THEMES.md](DARK-THEMES.md).
