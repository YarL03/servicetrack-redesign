Начните с **[интерактивного каталога](index.html)**. Откройте файл в обычном браузере: сервер, установка пакетов и доступ к API не нужны. Выберите вариант, экран, ширину и светлую/тёмную тему. Ссылка «Открыть в полный размер» показывает макет без масштабирования каталога.

## Светлая и тёмная темы

В каждом варианте есть кнопка с солнцем/луной в правой части верхней панели. В каталоге переключатель находится рядом с выбором ширины. Выбор сохраняется в браузере и передаётся между каталогом и превью. Переключение не сбрасывает заполненные поля, открытый диалог и положение прокрутки.

Прямые ссылки: [v1 тёмный](v1/index.html?theme=dark), [v2 тёмный](v2/index.html?theme=dark), [v3 тёмный](v3/index.html?theme=dark), [тёмный каталог](index.html?theme=dark). Параметр `?theme=light` открывает светлый вариант независимо от сохранённого выбора. Если локальное хранилище заблокировано, переключение работает в текущем окне, а тема передаётся через ссылки.

Палитры и правила: [DARK-THEMES.md](DARK-THEMES.md). Тёмные PNG лежат в `v1/previews/dark`, `v2/previews/dark`, `v3/previews/dark`; светлые — в родительских папках. Для каждой темы сохранены 60 снимков экранов на пяти ширинах и превью каталога.

## Размеры экрана

Использованы стандартные брейкпоинты установленного в проекте MUI (`front/node_modules/@mui/system/createTheme/createBreakpoints.js`). Размеры указаны в CSS px.

| Диапазон | Граница | Превью | Компоновка |
| --- | --- | --- | --- |
| xs | 0–599 | 390 × 844 | Одна колонка, карточки вместо таблиц, нижняя навигация, полноэкранные диалоги |
| sm | 600–899 | 768 × 960 | Выдвижное меню, формы в две колонки, карточки реестров |
| md | 900–1199 | 1024 × 960 | Компактная навигация, таблицы, перенос настроек конструктора |
| lg | 1200–1535 | 1440 × 960 | Полное рабочее место с контекстной колонкой |
| xl | от 1536 | 1920 × 960 | Расширенная сетка, ограниченная ширина основного содержимого |

В каталоге планшетный фрейм имеет высоту 1024 px для удобства просмотра; PNG используют 960 px. Высота окна не является брейкпоинтом. Макеты прокручиваются и адаптируются к промежуточным ширинам, включая 320 px.

- Загрузка, пустые результаты, ошибки, отсутствие соединения и прав, 404, тарифные ограничения, лимит диска, подтверждения удаления и потери изменений.

## Интерактивность и границы

Работают переходы, диалоги, мобильное меню, поиск по административным таблицам, ввод/валидация форм, выбор файлов, смена периода тарифа, локальное редактирование конструктора и JSON-импорт/экспорт. Деморегистрация использует код капчи `4K8M2`. Предпросмотр отчёта скачивает демонстрационный CSV.

Это макеты для выбора дизайна, без серверных операций. Сохранение, оплата, импорт в рабочую систему, смена статуса, настоящая регистрация и серверные скачивания представлены состояниями и локальными подтверждениями. Данные вымышлены; изменения не сохраняются после перезагрузки. Карта и прибор учёта нарисованы SVG; настоящие аудио/видеозаписи не включены. Авторизация и матрица ролей описаны в документации, но не ограничивают просмотр каталога.

Мобильный веб-интерфейс — предложение редизайна: сейчас проект предлагает скачать APK. Этот существующий экран тоже сохранён. Группы пользователей и печать АДПУ в текущем коде отключены и не представлены как действующие функции. Оплата картой/СБП/T-Pay недоступна; платёжная вкладка «Документы» остаётся состоянием «в разработке». Формирование счёта на тариф отделено от успешного подключения.

## Структура

```text
redesign/
├── index.html                 интерактивный каталог экранов и ширин
├── v1/, v2/, v3/
│   ├── index.html             независимый вход в каждый вариант
│   ├── theme.css              уникальная компоновка и оформление
│   └── previews/              светлые PNG; dark/ — тёмные PNG на пяти ширинах
├── shared/                    общие сценарии, примитивы и локальные данные
├── previews/catalog*.png      светлый и тёмный каталог
├── screens.json               машиночитаемый индекс
├── SCREENS.md                 ссылки на все экраны
├── *-COVERAGE.md               соответствие исходному функционалу
├── DIRECTIONS.md              токены и адаптивные правила
└── qa/                        воспроизводимая проверка браузером и результаты
```

Для передачи скопируйте всю папку `redesign`: варианты используют общие файлы `shared`. Папка `tasks/` уже исключена в `.gitignore`; макеты находятся локально и автоматически в коммит не попадут.

При необходимости локального HTTP-просмотра из корня проекта:

```bash
python3 -m http.server 8080 --directory tasks/redesign
```

Затем откройте `http://localhost:8080`.

## Проверка

Описание результатов: [qa/README.md](qa/README.md). Скрипт браузерной проверки не требует npm-зависимостей и использует Chrome DevTools Protocol. Доступный Chromium задаётся через `REDESIGN_BROWSER`, если локальный путь отличается:

```bash
REDESIGN_BROWSER=/path/to/chrome node tasks/redesign/qa/browser-check.cjs --full --theme=dark
REDESIGN_BROWSER=/path/to/chrome node tasks/redesign/qa/browser-check.cjs --capture-only --theme=dark --screenshots
```

Код рабочего приложения, зависимости и конфигурация сборки не изменялись.
