# v2 · Пульт

Откройте `index.html` или выберите «Пульт» в общем каталоге `../index.html`.

Горизонтальная диспетчерская: тёмная верхняя полоса, общая строка разделов, компактные таблицы и объединённая полоса показателей. Бирюзовый акцент отмечает текущее действие. На планшете и телефоне разделы открываются из меню, строки таблиц становятся карточками.

Брейкпоинты: 600 / 900 / 1200 / 1536 CSS px; поддерживается ширина от 320 px. Все экраны и состояния общие с v1 и v3, список доступен в каталоге. Тема полностью локальная, системные шрифты, внешних запросов нет.

## Цветовые темы

[Светлая](index.html?theme=light) · [Тёмная](index.html?theme=dark). Переключатель солнце/луна находится в верхней панели; выбор сохраняется, поля и диалоги остаются на месте. Тёмные PNG: `previews/dark/`.
