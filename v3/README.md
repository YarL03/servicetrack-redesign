# v3 · Маршрут

Откройте `index.html` или выберите «Маршрут» в общем каталоге `../index.html`.

Компактная боковая навигация, мягкие фиолетовые поверхности и более свободные рабочие формы. В карточке заявки контекст расположен слева от основной работы; на небольшом экране он становится первым блоком последовательной ленты. Крупные скругления и отдельные кнопки-вкладки выделяют этапы.

Брейкпоинты: 600 / 900 / 1200 / 1536 CSS px; поддерживается ширина от 320 px. Все экраны и состояния общие с v1 и v2, список доступен в каталоге. Тема полностью локальная, системные шрифты, внешних запросов нет.

## Цветовые темы
